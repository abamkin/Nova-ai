## ✨ Возможности

- 💬 **Диалоговый AI** — понимает естественный язык
- 🧠 **База знаний** — технологии, наука, история, искусство
- 🔧 **Исправление опечаток** — автоматическая коррекция ошибок
- 🎮 **Мини-игры** — КНБ, угадай число, викторина
- 🔢 **Калькулятор** — встроенные математические вычисления
- 😄 **Шутки и факты** — развлекательный контент
- 💡 **Советы и мотивация** — цитаты и мудрые мысли
- 🌙 **Тёмная/светлая тема** — переключение одной кнопкой
- 💾 **Сохранение истории** — чаты сохраняются в localStorage
- 📱 **Адаптивный дизайн** — работает на любых устройствах
- ⚡ **Быстрый** — работает без сервера, без API ключей
